# 真实感优化轮（Realism Pass）

场景资产已完成、需要把观感从"精致的模型"推到"看起来是真的"时用。

---

## 先定：哪一种"真实"

这一步不做，后面的优化会互相打架。

| 类别 | 内容 | 何时推进 |
|---|---|---|
| **渲染真实** | 光线传输、材质响应、镜头行为的物理正确性 | **几乎总是可以全力推进**，不破坏风格 |
| **叙事真实** | 灰尘、磨损、水渍、指纹、杂物 | **仅当目标风格是写实时** |

**很多参考图（尤其插画风、产品图、动画风）的高级感恰恰来自"理想化的干净"。** 给这类目标加磨损和杂物，是在做反向优化。

**在规格里明确写出目标属于哪一类，并把不允许的元素列进禁止事项。** 执行者被要求"提升真实感"时，本能反应就是加脏。

限量推进时的典型上限：水平面积尘遮罩仅影响 Roughness ≤5%、不改 Base Color；角落积尘同理；禁止磨损、划痕、污渍、破损。

---

## 按性价比排序

### 1. 边缘倒角（收益最高）

**完美的 90° 锐边无法承载高光。** 真实物体边缘有 1～3mm 圆角，会拉出一条细高光线——这是眼睛判断"实物"最快的线索。

- 几何倒角 2～3mm，2 段，角度限制 30°（避免圆滑面被误倒角）
- 倒角后必须加 Weighted Normal 修改器（顺序不能反，否则倒角处出现暗带）
- 优先处理镜头里有明确直边的物体

现代引擎的虚拟几何体技术下，面数增加几乎不构成问题。**不要为省面数跳过。**

### 2. 体积雾

见 `lighting-ue.md`。同时解决"灯像贴纸"和"空间没有深度"。

### 3. 不完美与非对称（几乎零成本）

所有东西完美对齐、完美水平、完美居中，是"游戏场景"和"真实房间"最容易分辨的差别。

- 家具：±0.5° 随机旋转、±2cm 随机位移（**排除建筑构件、基准物体、灯光**）
- 书不垛齐，抽一两本歪出来
- 织物不居中，偏一边
- 相框微微歪；成对物品打破等距

扰动后**必须检查穿模**，尤其靠墙家具。

**收益远超工作量。它决定"有人住"还是"样板间"。**

### 4. 接触与坐落

- **Contact Shadows** 逐灯设置（小物件"飘着"的解药，AO 覆盖不了这个尺度）
- **墙地交界必须有构造**：踢脚线，或至少 3mm 凹缝。直接对接是建模软件特征，不是建筑特征
- **物体压进软体表面**：压陷 + **边缘外挤**。只做压陷读作"沉进泥里"，加上外挤才是"压在上面"

### 5. Roughness 破坏与 Detail Normal

**场景里不应存在任何一个恒定 Roughness 的表面。** 真实表面的微观粗糙度永远不均匀；恒定值产生一整片完全一致的反光，那是塑料特征。每个材质叠一层低频噪波，幅度 ±0.08。

**Detail Normal**：很小的 tiling 微观法线，高频平铺叠加在主法线上。近看提供细节，远看自然消失。成本极低，效果显著。大面积物体（墙、地板）用较低贴图密度 + Detail Normal 补偿。

### 6. 材质分辨率一致性

如果地板是 512 px/m、家具是 2048 px/m，**即使各自单独看都不错，放在一起就是错的**——眼睛能察觉细节密度不一致，读作"贴图拼凑"。

定一个全场景 Texel Density 标准并逐个核对。允许有意识的偏离，不允许遗漏。

### 7. 动态（实时场景专属）

**完全静止的场景无论画质多高都读作精致的模型。** 这是实时相对静帧的唯一优势，也是最容易浪费的。

按性价比：环境动态（雨、水面）→ 机械运动 → 织物微动 → 火焰闪烁 → 屏幕内容 → 灯带微弱呼吸。

两条纪律：
- **用噪波驱动，不要用 Sine。** 规律的正弦一眼看出是程序化的
- **幅度要小。** 织物摆幅 2cm 以内、灯带呼吸 3% 以内。超了会读作故障

## 风格校准闸口

**Roughness 破坏做足之后，画面会比参考图"脏"一点。这是正常的，不是做错了。**

在这一步之后**强制暂停**，逐区域判断哪些物理正确性要为风格让步（典型处理：把破坏幅度从 ±0.08 降到 ±0.04）。

不设这个闸口，执行者会直接冲进反射优化阶段，而高质量反射会把所有材质问题放大一遍，那时排查成本高得多。

## 实时特有的画质杀手

这一节是离线渲染不会遇到、实时场景一定会遇到的问题。**它们是"看起来比渲染图差"的真正原因。**

| 问题 | 表现 | 处理 |
|---|---|---|
| **时域抗锯齿拖影** | 高速运动物体、细密几何出现残影抖动 | 提高时域质量；**高速旋转物体用拖影盘贴片，不要让几何真的高速转** |
| **GI 小光源噪点** | 灯带、小光源周围闪烁斑点 | 提高最终聚集质量；小发光体必须配区域光 |
| **屏幕空间反射边缘穿孔** | 移动镜头时反射在画面边缘消失 | 只能靠光追反射解决 |
| **阴影漏光 / 分离** | 物体阴影与本体脱开 | 调 Normal Bias；**不要靠加大 bias 硬压**，那会加剧分离 |
| **薄物体无阴影** | 窗帘、薄纱、叶片 | 检查 Two Sided 与 Cast Shadow As Two Sided |
| **倒角处暗带** | 边缘出现深色带 | Weighted Normal 必须在倒角之后 |

**有旋转机械 + 长毛/细密几何的场景，前两项几乎必然出现**，优先排查。

## 性能纪律

**每个阶段前后各测一次帧时间，报告 ms 增量。**

真实感优化极易在不知不觉中吃掉一半帧率。没有逐阶段数字，最后无法判断该砍哪一项。

取舍顺序参考：

| 优先保留 | 理由 |
|---|---|
| 体积雾 | 收益覆盖全画面 |
| GI 质量 | 下降会同时毁掉所有发光体，是全局性损失 |
| 边缘倒角 | 几乎零成本 |

| 优先削减 | 理由 |
|---|---|
| 毛发密度 LOD | 通常是最贵的单项；按相机距离衰减，虚焦区不需要真毛发 |
| Planar Reflection 分辨率 | 降到 35% 视觉损失很小 |
| 反射质量档位 | 降档优于直接关闭光追 |

相机基本固定的场景，**混合光照（静态烘焙 + 少量动态灯）的质量往往比纯动态 GI 更干净**，值得评估。
