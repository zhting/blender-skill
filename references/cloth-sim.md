# 压力布料模拟（抱枕 / 床品 / 软包）

适用于任何"缝两片布再充气"的软体：坐垫、抱枕、枕头、被褥、软包墙、填充玩偶。

**核心认知：蓬松是几何问题，不是材质问题。** 用细分 + 雕刻去憋，永远出不来"内部有气压"的张力。

---

## 建模：闭合壳体

1. 平面细分至 **80×80** 左右（更高会变慢且产生碎褶，破坏厚料的宽缓褶皱特征）
2. **先建顶点组，再做后续操作**：
   - `SEAM` — 边界顶点环。模拟后提取滚边、生成距离场的唯一可靠锚点
   - `EDGE_BAND` — 边界向内 3 圈。用于收紧边缘、保留平坦的"耳"部
3. 全选，沿法线**挤出**很小的距离（如 5mm）形成闭合流形

**用挤出而非"复制两片 + Bridge Edge Loops"。** 挤出的封闭性不依赖两个环的顶点数匹配，脚本执行成功率高得多。

**顶点组必须在挤出/布尔之前建。** 它能穿过修改器和 convert 存活，是模拟后唯一可靠的几何锚点。指望模拟后靠几何位置去猜缝线在哪，不可靠。

## 参数

| 参数 | 典型值 | 作用 |
|---|---|---|
| Quality Steps | 12 | 低于 8 会穿模 |
| Tension / Compression | 20 | 真布几乎不拉伸；低了像橡胶气球 |
| **Bending Stiffness** | **3～10** | **褶皱性格的总开关，见下** |
| Pressure | 按目标高度调 | 每 +0.3 约 +8mm（经验值） |
| **Target Volume** | **0** | 非 0 会覆盖压力，整个模拟失效 |
| Shrinking Factor | −0.02 ~ −0.05 | 负值使布料略大于版型，制造余量→自然褶皱 |
| Self Collision | 开，距离 2mm | 边角挤压处必开 |

### Bending Stiffness 是权重最高的参数

| 值 | 效果 |
|---|---|
| 0.5 | 丝绸：大量细碎褶 |
| 3～6 | 中厚织物 |
| 10+ | 厚绒/皮革：少量宽大缓褶 |

先定这个值，再调压力。反过来会来回打架。

## 三条硬性纪律

### 1. 不要 Pin 固定边界顶点

Pin 能得到平整方边，但会同时杀死**四角自然上翘**和边缘抽褶——恰恰是真实软体最有辨识度的特征。让气压把布往中心拉，四角自己会翘起来。

边缘充得过圆、丢了平坦的"耳"时，靠给边缘顶点组加**负 Shrinking** 解决，不要回头去 Pin。

### 2. 必须有碰撞面

加一块 Collision 平面让底部自然压平、接触边缘轻微外扩。

**这一项比任何材质细节都更影响可信度。** 没有它，成品是"漂在空中的气囊"。

### 3. 滚边必须在模拟烘定之后做

顺序反了，滚边会被当作布料一起解算，变成面条。

正确顺序：模拟 → 达标 → 在稳定帧 convert 成网格 → 依 `SEAM` 顶点组提取边界 → 转曲线 → 加 profile。

## 滚边与压线

**滚边**：独立材质，Roughness 比主体低约 0.1。它需要沿整条边界抓到一道连续高光，这道亮线是"缝制感"的主要来源；与主体共用材质会丢掉它。

**压线（Topstitch）**：**不建几何**。在 20mm 尺度上是纯着色细节。

推荐做法——把到滚边曲线的距离烘成命名属性，着色器再消费它：

```
Geometry Proximity (Target = 滚边曲线, Source = Edges)
  → Distance → Store Named Attribute "seam_dist"
```

着色器端用 Map Range 在目标距离处开一道 1.5mm 窄槽，混入 Normal。仅极特写才考虑真实线迹几何。

## 缝合附件（蝴蝶结、装饰扣等）

**附件底下的主体表面必须有浅凹陷 + 缝合点抽褶。**

五分钟的工作，但这是"缝上去"和"贴上去"的分界线。缺了它，附件会像图层浮在表面。

---

## 验收

见 `gates.md` 的软体模拟一节。核心三项：

- 包围盒 Z 高度达标
- 四角可见自然上翘（未被 Pin 压平）
- 底部有接触平坦区且边缘轻微外扩

---

## 症状 → 原因

| 症状 | 应检查 |
|---|---|
| 完全没有充气 | 非流形（漏气），或 Target Volume 非 0 |
| 像橡胶气球 | Tension/Compression 太低 |
| 褶皱太碎、像丝绸 | Bending Stiffness 太低 |
| 四角平齐、无上翘 | 误用了 Pin |
| 漂在空中 | 缺 Collision 平面 |
| 滚边变成面条 | 在模拟前做了滚边 |
| 找不到缝合线位置 | 挤出前未建 SEAM 顶点组 |
| 附件像浮在表面 | 缺凹陷与缝合点抽褶 |
| 穿模 | Quality Steps < 8，或未开 Self Collision |

---

## 何时改用专业布料软件

若可使用 Marvelous Designer 一类的缝制求解器：画版型 → 缝合 → 加滚边压线 → 充气，二十分钟出结果，褶皱质量高一个档次，导出网格回来只做着色。

通用求解器能做，但会花大量时间在调参数上。**在方案里主动提示这个选项**，让用户决定。
