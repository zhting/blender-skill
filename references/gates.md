# 验收门槛库（Verification Gates）

写任何 3D 执行规格时都读这一份。

**门槛的判据：**换一个执行者来做，会不会得出同样的结论？如果答案是"看情况"，那它不是门槛，只是建议。

## 几何完整性

| 门槛 | 判定方法 | 通过标准 | 不通过怎么办 |
|---|---|---|---|
| **流形封闭** | `select_non_manifold()` 计数 | **必须为 0** | 压力模拟会完全失效（漏气）。补洞后重测 |
| **布尔后清理** | 布尔操作后重测非流形 + 检查零面积面 | 0 | Merge by Distance 0.0001 + Delete Loose |
| **圆形分段** | 目视洞口/圆柱边缘 | 圆柱切割体 ≥ 64 段 | 低于此值洞口能看出多边形棱 |
| **偏心检测** | 绕预定轴旋转 45°，比对旋转前后包围盒中心 | 误差 < 0.1mm | 原点不在真实旋转中心，重设原点 |

**偏心检测的价值**：旋转部件的原点错位，在源软件里几乎看不出来，到引擎里才表现为"轮子松了"。那时排查成本极高，而这里一行代码就测出来。

## 软体模拟

| 门槛 | 判定方法 | 通过标准 |
|---|---|---|
| **充气高度** | 报告模拟稳定帧的包围盒 Z 值 | 达到设计值 ±5mm |
| **外扩量** | 报告 X/Y 尺寸 | 略大于原始版型（充气后外扩属正常），超过 +8% 说明压力过高 |
| **接触面** | 目视底部 | 与地面接触处有平坦区且边缘轻微外扩 |
| **褶皱性格** | 目视 | 宽缓褶（厚料）vs 细碎褶（薄料），须与设计意图一致 |

**调参方向**：高度不足 → 上调压力（经验值每 +0.3 约 +8mm）；出现气球感 → 先确认 target volume 为 0，再降压力。

## 毛发与绒面

| 门槛 | 判定方法 | 通过标准 |
|---|---|---|
| **红底测试** | 底布材质临时改纯红，从**低视角**和**俯视**各渲一张 | **任何位置透红即不合格** |
| **成簇结构** | 目视亮部 | 能辨认出一撮一撮的束，而非均匀绒面 |
| **顶端参差** | 目视轮廓 | 无水平切齐感 |
| **剪影边缘** | 放大观察外轮廓 | 有 1～2px 过渡，不是锐线 |

**红底测试是这一类任务的第一硬门槛。** 真实长绒地毯是不透的；只要能看见承载面，观者立刻判定为"稀疏的草"，后续所有着色工作都救不回来。

必须两个视角都测——俯视通过、低视角透红是最常见的情况。

## 照明

| 门槛 | 判定方法 | 通过标准 |
|---|---|---|
| **曝光已锁** | 报告曝光模式与偏移值 | Manual（或等效），且数值已记录 |
| **无残留直射** | 目视地面 | 目标为室内光主导时，不得有阳光亮斑 |
| **发光体可辨** | 目视 | 每个光源在画面中能看出"这是一盏灯" |
| **暗部存在** | 检查预设的 3 个位置（如床底、墙角、架下） | 存在真正的暗区，非灰蒙蒙 |
| **冷暖配比** | 目视估算 | 暖色区域面积占比符合设计（典型为 ≤ 20%） |
| **后处理生效** | 修改后目视确认 | 若"改了没反应"，检查 override 开关 |

**曝光锁定必须是第一个门槛。** 它是其余所有强度数值的基准；中途改动会使之前调好的全部失效。若必须改动，需报告并复核。

## 跨软件交付

**三项必测，缺一不可。** 把导出的资产重新导入一个空场景：

| 门槛 | 通过标准 |
|---|---|
| **尺寸** | 与原始一致，不得出现 100 倍或 0.01 倍偏差 |
| **轴向** | 与约定轴一致 |
| **原点** | 仍在设计的枢轴位置 |

三项任一不符，调整导出参数重试。**不要带着问题交付**——接收方会以为是自己的导入设置问题，来回排查成本极高。

| 附加检查 | 通过标准 |
|---|---|
| 材质槽名与顺序 | 与原资产完全一致（Reimport 场景） |
| 多部件装配 | 共享同一原点时，接收端相对位置全填 0 即可正确装配 |

## 真实感优化

| 门槛 | 判定方法 | 通过标准 |
|---|---|---|
| **性能增量** | 每阶段前后各测一次帧时间 | 逐阶段报告 ms 增量 |
| **边缘高光** | 目视硬表面直边 | 出现可见的细高光线 |
| **无恒定 Roughness** | 抽查材质节点 | 每个材质至少一层噪波打散 |
| **非对称** | 目视全景 | 找不到两件完全平行或等距的物体 |
| **周期可辨性** | 观察动态元素 30 秒 | 闪烁/摆动不呈现可辨识周期 |

**性能增量必须逐阶段报告。** 真实感优化极易在不知不觉中吃掉一半帧率；没有分段数字，最后无法判断该砍哪一项。

## 如何设计新门槛

好门槛的四个特征：

1. **二值或数值** — "透红了没有"而非"够不够密"
2. **不依赖审美** — 换个执行者结论相同
3. **能在阶段内完成** — 不需要等全流程跑完
4. **失败时指向明确** — 知道该回去改什么

**把主观目标转译成客观代理量**，是设计门槛的核心手法：

| 主观目标 | 客观代理量 |
|---|---|
| "够蓬松" | 包围盒 Z 高度达到设计值 |
| "够密" | 底色透出测试 |
| "转轴正不正" | 旋转前后包围盒中心偏移 |
| "光够不够暗" | 指定 3 个位置是否存在暗区 |
| "有没有 CG 感" | 硬边是否产生高光线 |

找不到代理量时，退而求其次：**要求执行者报告具体数值而非结论**。让人来做最终判断，但至少判断依据是客观的。

**任务是"照设计图建模"时**，门槛不是现成的，需要从图纸里造出来（像素测量、关键点标注、剪影 IoU、特征清单）。完整方法见 `reference-matching.md`。
