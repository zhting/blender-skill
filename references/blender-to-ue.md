# 跨软件交付（Blender → 实时引擎）

原则通用，示例以 Blender → Unreal Engine 为主。

---

## 三项必测（不可跳过）

导出后**重新导入一个空场景**，报告：

| 项 | 通过标准 |
|---|---|
| **尺寸** | 与原始一致，不得出现 100 倍或 0.01 倍偏差 |
| **轴向** | 与约定一致 |
| **原点** | 仍在设计的枢轴位置 |

**不要带着问题交付。** 接收方会以为是自己的导入设置问题，来回排查成本极高。

导出参数组合存在不少版本相关的玄学。**不要相信"参数写对了就一定对"**——测。

---

## 原点约定：多部件共享枢轴

一个装配体（如可转动的机械、多层结构）拆成多个部件导出时：

**让所有部件的原点都落在同一点——那个装配/旋转的枢轴上。**

好处：接收端各组件的相对位置全填 `(0,0,0)` 即可正确装配，且旋转组件直接绕正确轴转，无需计算偏移。

多花两分钟设原点，省掉接收端一堆试错。

## 规范姿态

**把可动部件按"旋转轴 = 局部 Z"的规范姿态制作和导出**，到引擎里再旋转整个 Actor 就位。

若资产要与场景中某个已有结构配合（如嵌墙件与墙洞），把两件事分开：**结构改动在原位做，部件总成在规范姿态下单独做。** 试图同时满足两个坐标系会把自己绕进去。

## 设原点的操作顺序

```
1. 游标移到目标枢轴点
2. origin_set(type='ORIGIN_CURSOR')
3. 旋转到规范姿态
4. transform_apply(location=False, rotation=True, scale=True)   ← 注意 location=False
5. obj.location = (0, 0, 0)
```

**第 4 步应用 location 会把原点重置到世界原点，破坏刚设好的枢轴。**

## 偏心检测

设完原点，把部件绕预定轴旋转 45°，比对旋转前后的**包围盒中心**，误差须 < 0.1mm。

不一致说明原点不在真实旋转中心。这个 bug 在源软件里几乎看不出来，到引擎里表现为"轮子松了"，那时排查成本极高。

---

## 材质槽：最大的隐性风险

引擎按**槽名**匹配材质。改了材质名或调整了槽顺序，Reimport 之后材质分配就散了，需要手动重指。

**迭代模型时不要动材质槽。** 尤其是给已有资产做改动（如给墙开洞）时，不得新增、删除或重排材质槽。

**定下命名规范并写进规格**，让执行者从一开始就用对。

---

## 更新资产的三种情况

用错方式会白干：

| 想做的 | 正确操作 |
|---|---|
| 同一资产，几何改了要更新 | **Reimport**（保留路径、引用、引擎侧设置） |
| 用另一个已有资产顶替旧的 | **Replace References**，之后清理重定向器 |
| 关卡里已摆好的实例换网格 | Details 面板改，或 Replace Actors（保留变换） |

Reimport 记录的是导入时的源路径。团队协作时路径不同会失败，用 "Reimport With New File" 重指一次。

## 常规导出参数（需实测验证）

```
global_scale         = 1.0
apply_unit_scale     = True
apply_scale_options  = FBX_SCALE_NONE
axis_forward         = -Y
axis_up              = Z
bake_space_transform = False
use_mesh_modifiers   = True
mesh_smooth_type     = FACE
use_tspace           = True        # 法线贴图需要
use_triangles        = True
```

导出前 apply 旋转与缩放，否则引擎里的旋转轴会很奇怪。

---

## 不能通过网格格式交付的东西

**粒子毛发 / 程序化毛发。** 它是渲染时生成的曲线，网格交换格式里不包含这些几何。

两条路：
1. 转成真实曲线，走 Alembic 导入引擎的 Groom / Hair 系统
2. 改用 Shell 层片 + 位移方案

**开工前定路线**，两者资产结构完全不同，中途改要重做。

其他类似情况：程序化修改器的效果需先 apply；渲染器专有的着色节点不会跨越；模拟缓存需先烘定成静态网格。

---

## 症状 → 原因

| 症状 | 应检查 |
|---|---|
| 导入后尺寸差 100 倍 | 单位缩放参数组合，重测三项 |
| 旋转轴很奇怪 | 导出前未 apply 旋转 |
| 部件绕偏心轴转 | 原点不在真实枢轴，重做偏心检测 |
| 多部件装不到一起 | 未使用共享原点 |
| Reimport 后材质全乱 | 材质槽名或顺序被改动 |
| Reimport 报路径错误 | 源路径与本机不符，用 Reimport With New File |
| 毛发/绒毛完全没了 | 网格格式不承载曲线，需走 Groom 路线 |
| 修改器效果丢失 | 导出时未启用 mesh modifiers，或需先 apply |
