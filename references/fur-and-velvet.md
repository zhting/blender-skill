# 毛发与绒面（地毯 / 长绒 / 天鹅绒）

分两类，做法完全不同：

- **真实毛发几何** — 长绒地毯、皮草、羊羔绒。本文前半部分
- **绒面着色** — 天鹅绒、丝绒、短绒布料。本文后半部分

判断标准：**特写镜头需要毛发几何**，因为只有真几何能给出模糊的剪影边缘（真实绒面外轮廓有 1～2px 过渡，任何 shader 技巧都伪造不出）。中景及更远用着色即可。

---

# 一、真实毛发几何

## 第一硬门槛：不透

**从任何角度都不能看见底布。** 真实长绒地毯是不透的；能看见承载面，观者立刻判定为"稀疏的草"。

验证方法见 `gates.md` 的红底测试。**必须低视角和俯视都测**——俯视通过、低视角透红是最常见的情况。

## 双层结构

纯靠全长毛堆密度会爆内存。分工：

| 层 | 长度 | 密度 | 职责 |
|---|---|---|---|
| **底层** | 6～8mm | 高（约 150k/m²） | 只负责挡住底布 |
| **面层** | 18～25mm | 底层的 1/3 | 剪影与受光 |

底层材质比面层暗约 **15%**，直接给出绒层深处的自然衰减，比靠光线弹射算出来便宜得多。

短毛的内存与求解代价远低于同数量的长毛，这是双层方案成立的原因。

## Clumping 是权重最高的参数

真实长绒地毯是**簇状织造**，纤维天然成束。均匀撒点得到的是一片死板草坪；成簇之后，簇间缝隙与簇顶受光面产生的**微观明暗交替**，就是"蓬松"的全部视觉来源。

**优先用粒子系统的内置 Clumping**，不要用节点手搭。内置只需两个属性，手搭要建"撒簇心 → 最近邻 → 沿根尖插值收拢"整条链路，代码量差一个数量级。

| 参数 | 典型值 | 说明 |
|---|---|---|
| Clump Factor | 0.6～0.9 | 0 = 草坪 |
| Clump Shape | +0.45 | **正值**=根部不动尖端聚拢。负值是毛刷，不是地毯 |

## 单根形态

| 项目 | 值 | 说明 |
|---|---|---|
| 长度随机 | **±25%** | 顶端参差是"真"的第一信号，不可省略 |
| 段数 | 4～5 | 再多没意义 |
| 倾角 | 随机 15～30° | 全竖直 = 化纤门垫 |
| 整体倒向 | 轻微一致偏移 | 倒毛方向（nap），真地毯都有 |
| Kink | Wave，弱 | 不规则弯曲，不是卷曲弹簧 |
| **根/尖半径** | **接近相等** | 见下 |

**收尖是最容易照抄错的默认值。** 毛发系统的默认锥度是为动物毛设计的；**地毯纱线是均匀直径、几乎不收尖**。照搬默认会渲成"动物皮草"而不是地毯。tip/root 比值不低于 0.8。

## 着色：必须用专用毛发 BSDF

**不要在毛发上挂通用 Principled BSDF。**

毛发光学是 R / TT / TRT 三个 lobe。通用 BSDF 没有这套模型，给你的是一堆亮度均匀的细管子，怎么调都是化纤感。即使不谈逆光，TRT lobe 也在贡献纤维沿轴向的细高光——这是"像纤维"而非"像塑料丝"的关键。

| 输入 | 典型值 |
|---|---|
| Model | 微面元模型（粗纤维更准） |
| Roughness | 0.30 |
| Radial Roughness | 0.42 |
| Random Color / Roughness | 0.06 / 0.15 |

**两条纪律：**

- **颜色不要推向纯白。** 逆光的亮来自 TT 透射，不是靠提高反照率。albedo 拉满会让亮部暗部一起抬，绒层深度全丢
- **根尖渐变必做。** 尖端略亮、略暖、Roughness 略高（真实毛尖有磨损积灰）。成本近零，收益很大

## 渲染设置

| 设置 | 值 | 原因 |
|---|---|---|
| 曲线形态 | Ribbons | 比 3D 曲线快数倍，此尺度看不出差别 |
| **Transmission Bounces** | **≥ 12** | 光要穿过多层纤维；给低了绒层内部发死，变成平板 |
| **Clamp Indirect** | 10 或 0，**不要 1～2** | 最常见翻车点：为压萤火虫设太低，然后绒层不透气 |

降噪必须启用 Albedo/Normal 辅助通道，否则毛尖会被糊成塑料。

## 密度 LOD

爆内存时按到相机的距离衰减密度，而不是全局降密度。分界线藏在景深虚化里看不出来。

**不要为省内存降低近景密度**——那会直接毁掉红底测试结果。

# 二、绒面着色（天鹅绒 / 丝绒）

## Sheen 是全部

Sheen 模拟竖立纤维的逆反射，**只在光掠过表面时显现**。

| 输入 | 典型值 |
|---|---|
| Roughness | 0.8～0.9（绒面几乎纯漫反射） |
| Specular Level | **0.3**（默认 0.5 对布料偏高，会显塑料） |
| Sheen Weight | 0.7～1.0 |
| Sheen Roughness | 0.3～0.45 |
| Sheen Tint | 比主色更亮、更去饱和 |

**若最终看起来像磨砂塑料，优先怀疑场景缺掠射角光源，而不是回头调 shader。** 这是绒面材质最常见的误诊。

## 补充层

- **视角依赖增强**：Layer Weight (Facing) → ColorRamp → 混一个更亮的色进 Base Color。Sheen 只做了一半，这层让轮廓边缘再提亮
- **微观起伏**：两层弱 Bump（织物大结构 + 绒毛颗粒感），强度都不超过 0.06
- **Roughness 破坏**：用低频噪波在 0.75～0.9 间打散。绒面漫反射本就不均匀，统一值是塑料感第二大来源
- **UV 方向一致**：绒面有倒毛方向，同一块布的 UV 方向不一致会出现明暗断层

---

## 症状 → 原因

| 症状 | 应检查 |
|---|---|
| 像草坪 / 刷子 | Clump Factor 过低，或 Clump Shape 为负 |
| 像化纤门垫 | 倾角未随机，或误用通用 BSDF |
| 像动物皮草 | 收尖太强（tip/root < 0.8） |
| 一块死板的平板 | Transmission Bounces 太低 |
| 顶部边缘太齐 | 长度随机不足 |
| 稀疏、看得见底 | 缺底层，或底层密度不足 |
| 整体死白无层次 | 毛发颜色亮度过高 |
| 毛尖糊成塑料 | 降噪未启用辅助通道 |
| 绒层内部发灰发平 | Clamp Indirect 被设成 1～2 |
| 绒面像磨砂塑料 | 缺掠射角光源（不是 shader 问题） |
| 剪影边缘是锐线 | 中景以近需要真实毛发几何 |

---

## 跨引擎限制（重要）

**粒子毛发不能靠常规网格格式带到实时引擎。** 它是渲染时生成的曲线，网格交换格式里不包含这些几何。

两条路：

1. 转成真实曲线导出到引擎的 Groom / Hair 系统（通常走 Alembic）
2. 改用 Shell 层片 + 位移方案

**这个决策必须在开工前定**，两条路的资产结构完全不同，中途改要重做。
